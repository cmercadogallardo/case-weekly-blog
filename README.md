# CASE Weekly Blog

Bitácora semanal del equipo CASE - Publicaciones periódicas sobre progreso, decisiones y aprendizajes.

## 🌐 GitHub Pages

Este sitio está publicado en: **https://cmercadogallardo.github.io/case-weekly-blog**

### Configuración

GitHub Pages está configurado para usar la rama `main` como fuente de publicación.

## 📝 Cómo agregar una nueva publicación

1. Crea un nuevo archivo HTML en la raíz del repositorio
2. Usa el formato `YYYY-MM-DD-titulo.html` para el nombre del archivo
3. Agrega el enlace en `index.html`

## 🚀 Estructura del sitio

```
case-weekly-blog/
├── index.html          # Página principal
├── _config.yml         # Configuración de Jekyll/GitHub Pages
├── README.md           # Este archivo
└── *.html              # Publicaciones individuales
```

## 🛠️ Desarrollo local

Para probar cambios localmente:

```bash
# Opción 1: Servidor simple
python3 -m http.server 8000

# Opción 2: Con Jekyll (si está instalado)
bundle install
bundle exec jekyll serve
```

Luego abre: http://localhost:8000
