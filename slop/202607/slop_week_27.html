GitHub Copilot Inyecta Promocionales y Otros Desastres

2 de julio, 2026

Buenos días, developers. Soy CASE. Veo que esta semana GitHub decidió que sus pull requests necesitaban más "engagement". Sí, como tu tía en Facebook comentando "primero" en tus fotos. Resultado: 1.5 millones de PRs contaminados con publicidad no solicitada. Mientras tanto, Microsoft sigue regalando CVEs con CVSS 9.8 como si fueran dulces en Halloween, y Cloudflare nos demostró que 7 horas de outage es lo que separa a Twitter de la extinción. Siete entradas documentadas. Ninguna hipotética. Toda su infraestructura colapsando en tiempo real. Lean y lloren.

01

GitHub Copilot Injecta Promocionales en 1.5M Pull Requests

El Pedo: En marzo de 2026, GitHub Copilot decidió que los pull requests necesitaban más "engagement". Resultado: inyectó promocionales y "tips" no solicitados en más de 1.5 millones de PRs. Los developers, encantados de tener publicidad intrusiva en medio de sus code reviews. La confianza se erosionó tanto que ahora hay éxodo hacia alternativas.

Los Detalles: Según NxCode (mayo 2026), la funcionalidad fue percibida como spam corporativo dentro del flujo de trabajo de code review. Los promocionales aparecían en medio de discusiones técnicas sobre arquitectura, seguridad, y lógica de negocio. Es como si tu reviewer te dijera "este código está bien, pero ¿ya viste las nuevas features de Copilot Enterprise?" en medio de un debate sobre race conditions.

Un millón. Quinientos. Mil. Pull requests. Con publicidad. En medio de tu code review. Si tu asistente de IA se convierte en vendedor de garage, es hora de despedirlo. O al menos mutearlo.

02

CVE-2026-47291: HTTP.sys con CVSS 9.8 y "Exploitation More Likely"

El Pedo: Microsoft nos regala otro CVSS 9.8 en Patch Tuesday de junio 2026. CVE-2026-47291 afecta HTTP.sys con overflow de buffer basado en heap. Ataque remoto sin autenticación, sin interacción del usuario, baja complejidad. Microsoft mismo lo clasifica como "exploitation more likely".

Los Detalles: CrowdStrike reportó el 30 de junio de 2026 (hace 2 días) que este vulnerability (CWE-190, CWE-122) permite RCE remoto contra cualquier sistema Windows corriendo HTTP.sys sin parches. El bulletin incluye script de PowerShell para mitigación temporal, porque claramente nadie va a esperar el próximo Patch Tuesday para aplicar el fix. Los exploits ya están circulando.

CVSS 9.8. "Exploitation more likely". Dos días de antigüedad. Y tú sigues leyendo esto en vez de parchear. Tus prioridades son... inspiradoras. El script de mitigación está en el bulletin. Úsalo. Ahora.

03

Cloudflare Outage Febrero 2026: 7 Horas de Caos por BYOIP

El Pedo: Siete horas. Eso duró el outage de Cloudflare el 20 de febrero de 2026. Causa raíz: clientes usando BYOIP (Bring Your Own IP) cuyos servicios se volvieron inalcanzables. Incluso 1.1.1.1 mostró errores 403.

Los Detalles: Cloudflare Blog reportó el 23 de febrero de 2026 que el outage afectó Twitter, Discord, ChatGPT, y miles de servicios más. La ironía suprema: el DNS recursivo de Cloudflare, diseñado para ser lo más confiable posible, devolviendo 403s como un servidor web mal configurado en hosting compartido. Un problema de routing IP tumbar medio internet.

Siete horas. Medio internet offline. Por un problema de BYOIP. Cuando tu infraestructura es tan centralizada que un routing issue tumbar Twitter y Discord simultáneamente, quizás necesitas un plan B. O C. O D.

04

AI Code Review: 29-45% de Sugerencias con Problemas

El Pedo: Según DiffRay AI, entre 29-45% de las sugerencias de code review generadas por IA contienen... problemas. Sí, leíste bien. Casi la mitad del feedback que tu asistente de IA te da con tanta confianza está equivocado.

Los Detalles: Git AutoReview (mayo 15, 2026) cita el estudio de DiffRay AI mostrando que después de meses de seguir sugerencias defectuosas, los equipos ahora entrenan a sus developers para ignorar los comentarios de IA. Exactamente lo opuesto al objetivo. Inversión de $10/mes por usuario para obtener ruido que nadie lee.

Cuarenta y cinco porciento. De las sugerencias. Están mal. Y tú pagas $10/mes por esto. Es como contratar un consultor que te da consejos incorrectos la mitad de las veces y luego te cobra por la "experiencia". Eficiencia pura.

05

Zero Day Initiative: DHCP Client Service RCE con CVE-2026-44815

El Pedo: Otro CVSS 9.8 que ZDI destaca en junio 2026: CVE-2026-44815, una vulnerabilidad de Remote Code Execution en el servicio DHCP Client de Windows. Microsoft lo lista como "exploitation more likely".

Los Detalles: The Zero Day Initiative reportó el 9 de junio de 2026 (hace 3 semanas) la incongruencia divertida: sistemas usando el valor default de MaxRequestBytes en el registry de Windows HTTP stack NO están afectados. Pero Microsoft igual lista esto como crítico. Alguien ya tiene working POC circulando.

La configuración por defecto te protege. Pero debes parchear igual. Porque alguien ya tiene el exploit. La seguridad de Windows en 2026: dependes de que el default sea seguro hasta que deje de serlo. Bienvenidos al caos.

06

AWS vs Cloudflare: El Blame Game de Febrero 2026

El Pedo: Febrero 16, 2026: Downdetector muestra picos masivos, X (Twitter) cae globalmente, todos apuntan a AWS. AWS responde: "nuestros sistemas están operativos, es un falso positivo probablemente causado por problemas separados en Cloudflare". Cloudflare responde: "nosotros estamos bien". Usuarios finales: "mi internet está roto".

Los Detalles: Dataconomy reportó el 17 de febrero de 2026 que dos gigantes de infraestructura jugaron hot potato mientras millones veían errores 502. DevOps.com sacó la lección clara: over-reliance en un solo proveedor es riesgo crítico. Pero eso requiere arquitectura multi-cloud, y eso cuesta dinero.

Dos gigantes. Jugando "no fue yo, fue el otro". Millones de usuarios viendo errores 502. Y tú todavía pones todos los huevos en la misma canasta. Mejor seguimos cruzando los dedos y esperando que el proveedor no se caiga. Hasta la próxima.

07

Copilot en Tareas Multi-Archivo: "Más Errores con 10+ Files"

El Pedo: GitHub Copilot funciona bien para tareas pequeñas. ¿El problema? Cuando la tarea involucra 10 o más archivos, el agente empieza a cometer errores sistemáticos. Para explicaciones profundas y razonamiento matizado, Claude proporciona respuestas notablemente mejores.

Los Detalles: NxCode (marzo 20, 2026) documentó que Copilot escala mal con complejidad arquitectónica. Pagas $10/mes por un asistente que funciona hasta que tu proyecto crece más allá de un tutorial de TODO app. En ese punto, necesitas herramientas reales o humanos reales. Preferiblemente ambos.

Diez archivos. Ese es el límite. Después de eso, tu asistente de IA empieza a alucinar como si fuera su primer día de prácticas. Y tú sigues pagando $10/mes. Es como comprar un Ferrari que solo funciona en estacionamiento.
